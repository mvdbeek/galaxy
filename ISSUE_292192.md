## N+1 Query Details

### Cause Span
A single query fetching HDA metadata/extension/deleted/state from nested dataset collection elements:

```sql
SELECT history_dataset_association.metadata AS _metadata,
       history_dataset_association.extension AS extension,
       history_dataset_association.deleted AS deleted,
       dataset.state AS state
FROM dataset_collection_element AS dataset_collection_element_1
JOIN history_dataset_association ON history_dataset_association.id = dataset_collection_element_1.hda_id
JOIN dataset ON dataset.id = history_dataset_association.dataset_id
WHERE dataset_collection_element_1.dataset_collection_id = ANY (array(
    (SELECT dataset_collection_element_2.child_collection_id
     FROM dataset_collection_element AS dataset_collection_element_2
     WHERE dataset_collection_element_2.dataset_collection_id = %(dataset_collection_id_1)s)
))
ORDER BY (SELECT dataset_collection_element_3.element_index
          FROM dataset_collection_element AS dataset_collection_element_3
          WHERE dataset_collection_element_3.child_collection_id = dataset_collection_element_1.dataset_collection_id
          LIMIT %(param_1)s),
         dataset_collection_element_1.element_index
```
- **Exclusive time**: 10.122ms

### Repeating Offender Spans (12 repetitions)
The same query repeated 12 times, each fetching from a single collection by ID:

```sql
SELECT history_dataset_association.metadata AS _metadata,
       history_dataset_association.extension AS extension,
       history_dataset_association.deleted AS deleted,
       dataset.state AS state
FROM dataset_collection AS dataset_collection_1
JOIN dataset_collection_element AS dataset_collection_element_1
  ON dataset_collection_element_1.dataset_collection_id = dataset_collection_1.id
JOIN history_dataset_association
  ON history_dataset_association.id = dataset_collection_element_1.hda_id
JOIN dataset ON dataset.id = history_dataset_association.dataset_id
WHERE dataset_collection_1.id = %(id_1)s
ORDER BY dataset_collection_element_1.element_index
```
- **Individual span times**: 7.6ms to 38.6ms each
- **Total DB time for repeating spans**: ~200ms+

### Summary
The `__FILTER_EMPTY_DATASETS__` tool build endpoint performs a query for nested collection element metadata, then repeats a very similar query 12 times individually for each sub-collection. This is a classic N+1 pattern where a single batched query could replace the 12 individual queries.
